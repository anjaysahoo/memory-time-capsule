## Download & Optimization Instructions

1. Download each image from the "Image URL (landscape)" link above
2. Use Squoosh (https://squoosh.app/) or TinyPNG (https://tinypng.com/) to optimize
3. Target dimensions: 800x533px (3:2 aspect ratio)
4. Generate both WebP and JPG versions
5. Target file size: <100KB each (WebP ~60KB, JPG ~90KB)
6. Save with the filenames specified above to this directory
